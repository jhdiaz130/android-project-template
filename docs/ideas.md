# Ideas de proyecto

## Idea 1: Anggely Valentina Acero Moscoso

Una app donde el usuario registre ingresos y gastos diarios para mejorar la financiación y ver sus ingresos y egresos diarios, ayudar con sus ahorros y rastrear facturas. Registro de gastos por categoría (arriendo, comida, transporte). Gráficas (barras, pastel). Alertas cuando se excede un presupuesto. Tecnologías para usar: Flutter / Android Studio + Firebase/kotlin.


Aplicaciones similares:

- Wallet (by BudgetBakers): Permite conectar cuentas bancarias, categorizar automáticamente y establecer presupuestos personalizados.
- Fintonic: Muy popular para controlar gastos y recibir consejos financieros, disponible en Android e iOS.
- Money Lover: Ideal para crear presupuestos, gestionar deudas y rastrear facturas.
- Finerio: Permite la vinculación de tarjetas bancarias para categorización automática de ingresos y gastos, ideal para ahorro.
